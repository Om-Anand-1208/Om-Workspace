# SurferFlow Blender Kit

A self-contained starter kit to build a pastel 3D isometric surfing diorama in Blender.

## Quick start

```bash
blender --background --python surferflow_diorama.py -- --output-dir ./surferflow_output
```

Open `surferflow_output/SurferFlow_Diorama.blend` and use the six generated renders as consistent orthographic references. Read [`CODEX_BLENDER_GUIDE.md`](CODEX_BLENDER_GUIDE.md) for the modelling workflow, reference-image roles, Blender MCP notes, and a ready-to-copy Codex prompt.

The `.blend` is generated by Blender when you run the script; it is not pre-baked into this kit because the current build environment does not have Blender installed.
